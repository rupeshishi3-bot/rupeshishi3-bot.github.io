# Rupesh Bhagwan Ishi - AI Web Developer & Digital Architect Portfolio

A modern, high-performance portfolio application rebuilt with **React 18**, **TypeScript**, and **Vite**.

## Features Ported & Enhanced
- **Interactive Hero Experience**: Full-screen HTML5 Canvas particle system with mouse attraction, connection networks, dynamic typing effect, animated statistical counters, and 3D floating capability badges.
- **Cinematic UI & Aesthetics**: Dark futuristic digital theme, radial glow highlights, custom lagging cursor effects with scale animations on hover.
- **Interactive Terminal**: Simulated Linux terminal environment showcasing engineer philosophy and vision for AI-native web experiences.
- **Skills Matrix**: Categorized capability cards with animated skill-level progress indicators.
- **3D Tilt Projects & Services**: Card hover effects with dynamic 3D perspective shifts and tag classification.
- **Revolving Tech Orbit**: Dual-ring orbital animation showcasing full-stack and AI tool competencies.
- **Journey Timeline & Social Proof**: Milestone progression track and client testimonials.
- **Direct Contact System**: Form with real-time field validation, animated feedback, and Firebase Firestore persistence (`messages` collection) with local storage fallback.
- **Command Palette (Ctrl+K / Cmd+K)**: Quick fuzzy navigation modal for instant section jumping and actions.
- **Konami Code Easter Egg**: Secret overlay unlocked via `↑ ↑ ↓ ↓ ← → ← → B A` sequence or subtle footer hint trigger.
- **Floating Controls**: Back-to-top and command launcher.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Modern CSS variables, design tokens, responsive grid system
- **Icons**: Lucide React
- **Backend / Database**: Firebase Firestore (web SDK)

## Development
```bash
npm install
npm run dev
```

Dev server runs on `http://0.0.0.0:3000`.
